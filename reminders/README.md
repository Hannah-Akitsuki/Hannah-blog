# 本地计划提醒（Windows）

站内「计划」是公开只读的；网页通知只在页面开着时有效。这个脚本负责网页关掉后的提醒：
读取同目录的 `plan.json`，每 60 秒检查一次，到点弹窗 + 响铃，可「稍后 5 分钟」。

## 依赖

- Windows 10 / 11
- Python 3（安装时勾选 “Add Python to PATH”；tkinter 随官方安装包自带）
- 不需要 `pip install` 任何第三方包

## 用法

1. 打开博客，进入站主模式（`?owner=1` 或连点左上角标题 5 次），进入「计划」。
2. 点「导出 JSON」，得到类似 `plan-20261109.json` 的文件。
3. 把它改名为 `plan.json`，放进本目录（和 `watch_plan.py` 同目录）。
4. 双击 `run_reminder.bat`，保持这个窗口开着。

之后在站内改计划，重新导出并覆盖 `plan.json` 即可，脚本每分钟会自动重新读取。

## 它会怎么提醒

- 每 60 秒重新读取一次 `plan.json`。
- 只提醒状态不是「完成」的计划；到点弹窗并响铃。
- 弹窗里可以选「稍后 5 分钟」或「知道了」。
- 电脑休眠醒来后，错过 15 分钟以内的计划仍会补一次提醒；超过 15 分钟就不再补。

## 如实说明的限制

- 电脑必须开机、不进入睡眠，脚本窗口必须一直开着，否则不会提醒。
- 网页端通知只在页面开着时有效；静态站没有后端，浏览器关掉后不可能推送。
- 不做账号体系、不做云端同步；换设备用站内的导出 / 导入。
- `plan.json` 已写进本目录的 `.gitignore`，不会被提交。公开版本由站内「发布」写入仓库的 `data/plans.json`。

## 数据格式

就是站内「导出 JSON」得到的格式，示例见 `plan.example.json`：

```json
{
  "app": "hanhe-plan",
  "version": 1,
  "items": [
    { "id": "demo-1", "date": "2026-11-09", "start": "09:00", "end": "10:00", "title": "读书", "status": "todo", "note": "" }
  ]
}
```

`date` 为 `YYYY-MM-DD`，`start` 为 24 小时制 `HH:MM`；`status` 为 `todo` / `doing` / `done`。
