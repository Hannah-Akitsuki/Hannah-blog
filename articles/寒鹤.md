# 寒鹤

你好，我是**寒鹤**，一个还在读书的大学生，欢迎来到我的个人博客。

我把这里当作整理自己的地方：白天上课，课后把听过的、读过的、查到的零散内容收拢成一篇篇笔记。目前笔记以 FZU 课程为主：编译原理、系统架构、软件工程、操作系统、计算机网络。写得慢，但会一直写。

## 我在关心什么

- **K-pop**：歌单里常年循环的那几首，舞台和编舞会看，回归期的物料也不想错过。
- **二次元**：追新番，也补旧番，遇到喜欢的作品会去找设定集和评论，把没看懂的地方补上。
- **OC**：给自己的人物写设定、画一点草图，替他们安排性格、说话方式和彼此的关系。
- **看书**：课内课外的都读，读到有用的段落会记下来，之后可能就变成一篇笔记。
- **旅行**：喜欢换一座城市走走，看看街道，吃当地的东西，回来写几段记录。

## 这个站会写什么

课堂笔记整理、读书与观影的随想、OC 的人物与世界观，还有旅途中记下的片段。不定期更新，欢迎在留言榜留言。

## 关于本站

- 笔记大多整理于飞书，导出为 Markdown 后托管在 GitHub Pages
- 部分文章设有定时公开，到期自动解锁
- 支持侧边目录跳转、暗色模式与在线编辑预览
